# 《拾线铺》核心重设计 v2（推翻倒线团）

> 2026-10-31 · 对标《抓大鹅》（关卡情绪 + IAA）×《浪漫餐厅》（元层留存 + IAP）
> 硬约束不变：零外部资源（Canvas 程序化 + WebAudio）、单指点击、无版号前零真实付费、不卖数值。
> 数据口径：竞品数据均为第三方估算/公开榜单（2026-10），非财报。

---

## 0. 结论先行

1. **倒线团整体作废**：信息全公开 + 每步只挪一格 + 无失败 = 无期待感、无付费点、无传播点，商业上不成立。
2. **新玩法 =「拾线关」（抓大鹅式堆叠拾取 + 7 格线篮三消）+「织补铺」（浪漫餐厅式二合 + 修店 + 章节剧情）**。
   关卡负责"爽 + 输 + 广告"，铺子负责"盼 + 留 + 未来内购"。这正是当前微信畅销榜休闲头部的「消除 + 经营」混合范式（梦幻消除战、开心消消乐装修线同构）。
3. **2D 分层堆叠（羊了个羊式遮挡）即可实现**，不需要 3D，符合零资源铁律。
4. **商业路径**：上线期纯 IAA（复活 / 洗牌 / 体力 / 翻倍）→ 拿到版号后开小额 IAP（¥3~25 礼包，卖节奏不卖数值）。

## 1. 核心循环

```
┌─ 拾线关（30~90 秒）──────────────────────────────┐
│ 点堆叠中未被遮挡的线团 → 进 7 格线篮 → 3 同色自动消 │
│ 清空堆叠 = 胜；线篮满 = 败 → 看广告复活 / 重来       │
└──────────────┬───────────────────────────────────┘
               ↓ 产出：线材（按本关颜色）+ 金币 + 体力消耗
┌─ 织补铺（元层）─────────────────────────────────┐
│ 线材投入 4×5 合成盘：线头→线团→线球→围巾→毛衣→挂毯 │
│ 交付顾客订单 → 金币 / 星星 → 修复铺子物件（灰→彩）   │
│ 修完一章 → 解锁剧情段 + 新顾客 + 新合成链             │
└──────────────┬───────────────────────────────────┘
               ↓ 剧情悬念 / 订单缺料
          回到拾线关（定向打某颜色的关）
```

**一步记四本账**：一次消除同时推进 ①本关进度 ②线材库存 ③周活动积分 ④章节修复度。

## 2. 拾线关（抓大鹅层）

| 要素 | 设计 | 情绪目的 |
|---|---|---|
| 堆叠 | 3~8 层错位网格，被上层遮挡的线团压暗不可点 | 未知：揭开下层 = 每步一次小开箱 |
| 线篮 | 7 格，同色 3 个自动消除；第 6 格起篮子变红 + 心跳音 | 危险可见、"差一点" |
| 胜负 | 堆叠清空胜 / 线篮满败 | 有输才有赢的爽 |
| 道具（每关各 1 次免费，额外看广告） | **抖篮**（洗牌，整屏晃动，对标颠锅）· **退回**（篮中 3 个放回顶层）· **透视**（下层显色 3 秒） | 手感 + 自然广告位 |
| 关卡节奏 | 第 1 关教学必过；**第 2 关故意卡点**（通过率目标 20~30%）；之后"易-易-难"三拍循环 | 社交话题"你过了吗" |
| 每日挑战 | 全服同题（复用 `hashSeed`+`mulberry32`），分享卡"今日仅 X% 织完" | 传播 |

**可解性**：生成器反向构造——先定解序列（每 3 个同色为一组按序放入），再逆序堆叠出遮挡关系，保证存在解；难度旋钮 = 层数、颜色数、同屏可点数、"诱饵"错位数。卡点关允许"有解但需要道具大概率才能过"（抓大鹅同款），需在验证桩中用模拟玩家量化通过率。

## 3. 织补铺（浪漫餐厅层）

| 要素 | 设计 |
|---|---|
| 合成盘 | 4×5 格，二合；格子有限 = 天然节奏器 |
| 合成链 | 每色 6 级：线头→线团→线球→围巾→毛衣→挂毯（Canvas 程序化图标） |
| 订单 | 同时 2~3 位顾客，需求如"红围巾 ×1 + 蓝线球 ×2"，交付得金币 + 星星 |
| 修店 | 星星点亮铺子物件（招牌、织机、货架、窗帘…每章 8 件），场景灰→彩（复用 `CHAPTERS` 色板 + 剪影） |
| 剧情 | 每修 2 件出一段 3~5 句文字对话，章末悬念；5 章 × 4 段 = 20 段固定文本，**不做周更**（无内容产能） |
| 角色 | 文字 + 程序化剪影头像：店主奶奶 / 灰雾里的神秘客人 / 偷线的黑猫（悬念线） |

## 4. 经济与变现

| 资源 | 来源 | 消耗 |
|---|---|---|
| 体力（满 30，5 分钟回 1，进关 -5） | 自然回复 / 看广告 +10（日上限 5 次） | 拾线关 |
| 线材 | 拾线关 | 合成盘 |
| 金币 | 订单、关卡 | 道具、扩合成盘格子、皮肤 |
| 星星 | 订单 | 修店（剧情推进，唯一出口） |

**IAA 广告位（上线期）**：失败复活（最高转化）· 道具补充 · 体力 · 结算翻倍 · 合成盘"一键整理"。频控：插屏不进关卡内，激励视频全部玩家主动触发。

**IAP（版号到手后）**：体力包、合成盘扩格、章节加速礼包、外观。❌ 不卖星星、不卖必过、不做抽奖开箱。
