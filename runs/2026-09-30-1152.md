## 一、分享界面（已完成，`index.html`）

| 模块 | 实现 |
|---|---|
| 链接取值 | `shareUrl()`：`http(s)` 环境取 `location.href`（**GitHub Pages 上自动就是线上地址**）；`file://` / 本地预览回落常量 `GH_PAGES_URL` |
| 复制 | `copyText()` 三级降级：`navigator.clipboard.writeText` → `document.execCommand('copy')`（隐藏 textarea）→ 返回 false 由 UI 提示手动复制 |
| 海报 | `makePoster()` 纯程序化绘制 480×720（DPR2）：渐变底 + 白卡 + 标题 + **与游戏同款 3 根管子示意**（复用 `ballPos` 同款算法 + `PALETTE`） + 玩法一句话 + **自适应字号链接框**（`measureText` 循环缩字号） + 页脚；`toDataURL('image/png')` 后 `<a download>` 保存 |
| 入口 | `openEntry("share")` → `showShare()`，左栏「📤分享」直达（不再走预告弹窗） |
| 激励 | 每日首次分享 +30 金币（`shareClaimedDate` 存档，幂等：同日重复分享不重复发） |
| 小游戏端 | `wx.shareAppMessage` 保留为注释占位 |

## 二、GitHub 发布（准备完成，**推送被权限拦住**）

已完成：
- `.github/workflows/pages.yml`：`actions/configure-pages@v5`（`enablement: true` 自动开启 Pages）+ 只把 `index.html` 做成站点产物上传（`_site/`，含 `.nojekyll`）→ **设计文档不会暴露到公网站点**
- `README.md`（含玩法/功能表/技术要点/四约束/部署说明）、`LICENSE`(MIT)、`.gitignore`（排除 `.workbuddy/` 本地记忆与自动化日志）、`.gitattributes`（统一 LF）
- 本地 `git init -b main` → 提交 20 个文件（commit `829431c`）→ `origin` 指向 `https://github.com/MasonLee996/sort-master.git`

**阻塞**：GitHub 连接器是**只读**授权，两个关键操作均返回
`403 Resource not accessible by integration`：
1. `create_repository` → 无法创建仓库
2. `create_or_update_file`（写入 `README.md`）→ 无法写文件

→ 已排查本地无可复用凭据：无 `gh` CLI、无 `~/.git-credentials`、`CODEBUDDY_MCP_CONFIG` 里只有 WorkBuddy 会话令牌（非 GitHub PAT）。

**解除方式（二选一）**
- 在 WorkBuddy 连接器管理里重新授权 GitHub，授予 `Repository permissions → Contents: Read and write`（若还想让 AI 直接建仓库，再加 `Administration: Read and write`）
- 或用户自行在 GitHub 网页建**空公开仓库** `sort-master`，然后用自己的凭据 `git push -u origin main`

两条路径的 Pages 地址**完全相同**：`https://masonlee996.github.io/sort-master/`
（项目仓库名为 `sort-master`，或用户站点仓库下的 `sort-master/` 子目录，URL 一致 —— 分享弹窗里的回落常量对两种方案都正确）
