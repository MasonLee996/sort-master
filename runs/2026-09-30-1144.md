# 第 92 轮 · 每日谜题（按日期定种子的全服同题关卡）

时间：2026-09-30 11:44
来源：backlog P1 最高优先级未完成项（上轮已为它预留入口，本轮把「预告弹窗」变成真功能，形成 入口→功能 闭环）

## 一、做了什么（`index.html`）

| 模块 | 内容 |
|---|---|
| 确定性随机 | 新增 `hashSeed(str)`（FNV-1a 字符串散列）+ `mulberry32(a)`（32 位 PRNG），零依赖，同日期必得同一序列 |
| 生成器改造 | `randomFill(colors, empties, rnd)` 新增可选随机源参数；`rnd = rnd || Math.random` → **普通关卡行为零变化**，每日谜题注入日期种子 |
| 每日题面 | `dailyColors(ds)` 预告今日颜色数（5~7）+ `genDaily(ds)` 生成并沿用 `solve()` 校验**保证可解**（400 次重试 + 第 200 次兜底加空管） |
| 独立模式 | 新增 `mode`（`"normal"`/`"daily"`）：每日模式 HUD 关卡位显示「每日」、**不限步**、不计入关卡星级；`startLevel` 显式置回 `normal` |
| 奖励 | 每天一次**首通 +60 金币**（`dailyDoneDate`/`dailyMoves` 存档），同日二次通关只发基础奖励 |
| 入口弹窗 | `#dailyOverlay`：题面日期（"全服同一关"）+ 今日颜色数/管数/不限步 + 完成状态（含首通步数）+ 按钮「开始挑战 / 再玩一次 / 关闭」，**已在每日模式时**才出现「退出每日，回到闯关」 |
| 通关弹窗 | 每日模式下按钮文案改为「再玩一次 / 回到闯关」，避免玩家误以为能"下一关" |
| 红点 | `refreshRail()` 扩展：除「签到待领取」外，**「每日谜题今日未通关」也亮红点**，通关即熄灭 |
| 生成遮罩 | `#genOverlay` 文案参数化（`第 N 关` / `每日谜题 2026-9-30`），不再硬编码"第 X 关" |
| 说明弹窗 | 过关说明新增一条，告诉玩家左右两侧入口栏是什么、点了会怎样 |
