# 第 91 轮 · 活动入口侧栏（留存/活跃/促销常驻入口）

时间：2026-09-30 11:38
来源：用户反馈 ——「这种留存性质或者促进活跃的活动，或者促销的东西应该得有个入口显示才对，
可以放在游戏的左右两侧，按列放置，可以滑动，里面有很多按钮，点哪个出来哪个」

## 一、做了什么

需求属于"一整个 UI 系统"，按铁律**先出规格再做最小实现**。

### 1) 规格：`design_specs/activity_center.md`（新建）
含 背景与问题 / 目标与非目标 / 方案设计（交互视觉·双栏分工·棋盘避让·路由规则）/
数据结构 / 接口清单 / 验收标准 7 条 / 风险对策表 6 行 / 后续演进 4 项。

### 2) 实现：`index.html`

| 改动点 | 内容 |
|---|---|
| CSS | 新增 `.rail` 侧栏样式：`position:absolute; top:50%; translateY(-50%)`、宽 42px、`max-height:66%`、`overflow-y:auto`（**可滑动**）、隐藏滚动条、`touch-action:pan-y`、`z-index:10`；`#railL{left:3px}` `#railR{right:3px}`；按钮 emoji 16px + 标签 9px；`.hot` 高亮；`.dot` 红点 |
| HTML | `#stage` 内 `#toast` 之后插入 `<div class="rail" id="railL">` / `#railR`；新增通用预告弹窗 `#entryOverlay`（`#entryIco`/`#entryTitle`/`#entryDesc`/`#btnEntryClose`） |
| JS | 新增 `RAIL_ITEMS`（左 4 + 右 4）、`ENTRY_META`（文案元数据）、`railBtns`/`railDots`、`buildRail()`、`refreshRail()`、`showEntry(id)`、`openEntry(id)` |
| JS | `layout()` 的 `marginX` 由 `16` → `16 + RAIL_PAD`（新增全局 `let RAIL_PAD = 48`），**给侧栏预留安全区，管子永不被压住** |
| JS | 抽出 `showHelp()`（原 header「?」内联箭头函数改复用） |
| JS | `claimSign()` 末尾 + 启动 `detectSign()` 之后调 `refreshRail()` → 签到待领取时「签到」按钮亮红点 |

### 3) 双栏分工
- 左栏（留存/活跃）：📅签到（带红点角标）、🧩每日、📤分享、🏆排行
- 右栏（促销/变现）：🛒商城、🎁首充、💳月卡、🚫去广告

### 4) 路由（点哪个开哪个）
```
openEntry(id)
 ├─ "sign"  → showSign()                       已实现，直达签到弹窗
 ├─ "noads" → btnNoAds.click()                 已实现，复用内购去广告流程
 └─ 其它    → showEntry(id)                    通用「功能预告」弹窗（读 ENTRY_META）
```
新增一个活动 = `RAIL_ITEMS` 加一条 + `openEntry` 加一个分支，不动布局代码。
