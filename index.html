过关说明

  1. 怎么操作：点一根「源管」选中（变蓝高亮）→ 再点「目标管」倒过去。想换选择，点回原管取消。
  2. 什么情况能倒：目标管是空的，或者目标管顶部颜色和源管顶部相同；一次会把源管顶部连着的同色球一起倒完（受目标管剩余空间限制）。
  3. 过关条件：把每种颜色全部收进同一根管，做到每根管里只剩一种颜色（或空着），即过关。
  4. 卡住了怎么办：底部「撤销」回退一步；「提示」会直接指出可行的下一步（蓝框 = 源管，琥珀框 = 目标管）。
  5. 步数限制：第 7 关起有步数上限（本关参考解步数 ×1.35），顶部会常显剩余 N 步，剩 ≤5 步时变红告警；用完可看广告 +5 步（每关最多 2 次，去广告用户免费领取同奖励），或用金币 40 换 5 步。广告加步属辅助操作，本关最高只能拿 ★★。前期关卡不限步，看广告改为领金币。
  6. 星级怎么算：基准步数 = 本关参考解步数 ×1.15。★★★ = 没用任何辅助（撤销 / 提示 / 广告加管 / 广告加步）且步数 ≤ 基准；★★ = 没用辅助但步数超过基准，或用了辅助但步数 ≤ 基准；★ = 其余（用了辅助且超过基准）。广告加步（看广告或金币兑换）同样计入辅助操作，本关最高 ★★，护星徽章可免。星越高金币越多。
  7. 步数超过基准会掉星：即使一次辅助都没用，只要通关步数超过基准步数，最高也只有 ★★ —— 想拿 ★★★ 得既不碰辅助、又走得足够省。
  8. 护星徽章与商城：右侧「🛒 商城」可用金币兑换提示券 / 撤销券 / 护星徽章 / 管身皮肤（只卖便利与外观，不售卖任何数值）。其中护星徽章本关生效：用了辅助也不掉星，仍按步数评星。
  9. 加管上限：死局时看广告可加一根空管，每关最多 3 次，用满后只能撤销回退或重开本关 —— 避免无限加管把局面刷成"能过但没意思"。
  10. 难度怎么递进：关卡越高，颜色越多、管越多、空管更少，逐步变难。
  11. 左右两侧的小按钮：常驻入口栏（可上下滑动）。左侧是签到（连续 7 天阶梯奖励）、每日谜题（每天一道全服同一题面，不限步，首通 +60 金币）、分享（复制链接 / 生成海报，每日首次 +30 金币）；右侧是商城（金币兑换道具）、首充 / 月卡 / 去广告等。点哪个开哪个。
