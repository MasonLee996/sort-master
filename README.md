# 收纳大师 · Sort Master

> 纯 AI 生成的 H5 收纳 / 倒球解谜小游戏。**零美术依赖**（全部程序化 Canvas 绘制 + WebAudio 合成音效），**单文件 `index.html`**，双击即可运行。

**在线试玩**：https://masonlee996.github.io/sort-master/

---

## 玩法

1. 点一根「源管」选中（变蓝高亮）→ 再点「目标管」倒过去。
2. 目标管**是空的**，或**顶部颜色与源管顶部相同**时才能倒；一次把源管顶部连着的同色球一起倒完（受目标管剩余空间限制）。
3. 把每种颜色全部收进同一根管，做到**每根管里只剩一种颜色（或空着）**即过关。

## 功能一览

| 模块 | 说明 |
|---|---|
| 核心循环 | 点选源管 → 点选目标管 → 合法倒球 → 全单色过关 |
| 关卡生成 | 程序化随机填充 + DFS 求解器校验，**保证每关可解**（1~40 关实测 fail=0） |
| 提示 | 复用求解器给出可行的下一步 |
| 撤销 / 重开 | 无限撤销（步数同步回退） |
| 限步挑战 | 第 7 关起有步数上限（颜色数 × 8），用完可看广告 +5 步 |
| 星级评级 | 零辅助 = ★★★ / 步数达标 = ★★ / 否则 ★ |
| 手感 | 倒球沿二次贝塞尔弧线飞入目标管、逐颗错峰；选中管呼吸光晕 + 上指箭头 |
| 死局出口 | 无合法步时弹「无路可走」→ 撤销 / 看广告加管 / 重开 |
| 活动入口 | 左右两侧常驻**可滑动**入口栏：签到 / 每日谜题 / 分享 / 排行 · 商城 / 首充 / 月卡 / 去广告 |

| 每日谜题 | 按日期定种子的固定题面（**全服同一关**，可 PK），不限步，首通 +60 金币 |
| 分享 | 复制 GitHub Pages 链接 / 程序化生成分享海报，每日首次 +30 金币 |
| 多尺寸自适应 | 500×600 / 500×160（矮窗）/ 340×640（窄屏）均通过渲染回归 |

## 技术要点

- **零外部资源**：无 CDN / 图片 / 字体 / 音频文件。球与管子全部用 Canvas 路径绘制，音效用 WebAudio 振荡器合成。
- **单文件可运行**：`file://` 直接打开即可玩；`localStorage` 全部包在 `try/catch` 中（隐私模式下不崩）。
- **确定性每日题面**：`hashSeed`（FNV-1a）+ `mulberry32` 注入 `randomFill(colors, empties, rnd)`，同日期必得同一题面；普通关卡不传 `rnd` 时仍走 `Math.random`，行为完全不变。
- **异步生成防白屏**：`startLevel` 先弹生成遮罩让出主线程再生成，`genToken` 防止快速切关时旧生成覆盖新关。
- **可回滚的手感层**：倒球动画只负责表现，逻辑态即时更新；动画期间锁输入，避免状态机串扰。
- **变现钩子**：激励视频（+5 步 / 金币）、内购去广告卡均为占位实现，接入微信小游戏后替换为 `wx.createRewardedVideoAd` / `wx.requestMidasPayment`。

```bash
python -m http.server 8080
# 浏览器打开 http://localhost:8080/index.html
```

## 设计红线（四约束）

1. 单指点击操作，3 秒内理解玩法
2. 难度渐进递升，不靠数值售卖
3. 广告与内购钩子保留，但不影响可玩性
4. 零外部资源依赖，单文件可运行
