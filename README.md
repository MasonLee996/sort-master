# 收纳大师 · Sort Master

> 纯 AI 生成的 H5 收纳 / 倒球解谜小游戏。**零美术依赖**（全部程序化 Canvas 绘制 + WebAudio 合成音效），**单文件 `index.html`**，双击即可运行。

**在线试玩**：https://masonlee996.github.io/sort-master/

---

## 玩法

1. 点一根「源管」选中（变蓝高亮）→ 再点「目标管」倒过去。
2. 目标管**是空的**，或**顶部颜色与源管顶部相同**时才能倒；一次把源管顶部连着的同色球一起倒完（受目标管剩余空间限制）。
3. 把每种颜色全部收进同一根管，做到**每根管里只剩一种颜色（或空着）**即过关。

## 功能一览

| 模块 | 说明 |
|---|---|
| 核心循环 | 点选源管 → 点选目标管 → 合法倒球 → 全单色过关 |
| 关卡生成 | 程序化随机填充 + DFS 求解器校验，**保证每关可解、且开局不是已完成态**（1~40 关实测 fail=0） |
| 提示 | 复用求解器给出可行的下一步；**源管蓝框 + 目标管琥珀虚线圈**同时高亮，一眼看清从哪倒到哪 |
| 撤销 / 重开 | 无限撤销（步数同步回退）；**撤销不会吞掉「看广告加管」换来的空管** |
| 限步挑战 | 第 7 关起有步数上限（`ceil(该关解步数 × 1.35)`），HUD 显示「剩余 N 步」（≤5 转警示色），用完可看广告 +5 步。**当前只提示、不阻断落子**（是否升级为失败态属产品决策，见 `optimization_backlog.md`） |
| 星级评级 | 基准 `par = ceil(该关解步数 × 1.15)`（与限步同源，都用生成时求解器给出的参考步数）。零辅助且 ≤par = ★★★ / 零辅助超 par 或 辅助且 ≤par = ★★ / 其余 ★；用**护星徽章**可保留本关星级 |
| 手感 | 倒球沿二次贝塞尔弧线飞入目标管、逐颗错峰；选中管呼吸光晕 + 上指箭头 |
| 死局出口 | 无合法步时弹「无路可走」→ 撤销 / 看广告加管（每关上限 3 次，HUD 常驻记录）/ 重开 |
| 活动入口 | 左右两侧常驻**可滑动**入口栏：签到 / 每日谜题 / 分享 / 排行 · **道具商城** / 首充 / 月卡 / 去广告 |
| 道具商城 | **金币兑换**（无付费入口）：提示券 ×1 / 30、撤销券 ×5 / 100、**护星徽章 ×1 / 150**、皮肤 磨砂 200 / 玻璃 350 / 木纹 500；金币不足置灰。这是金币的**消耗出口**（此前金币只进不出） |
| 每日签到 | 按本地日期判连续（断签重置、第 7 天循环），7 天阶梯奖励 20→100 金币 |
| 每日谜题 | 按日期定种子的固定题面（**全服同一关**，可 PK），不限步，首通 +60 金币；通关弹窗生成「日期 + 步数」分享文案 |
| 分享 | 复制 GitHub Pages 链接 / 程序化生成分享海报，每日首次 +30 金币 |
| 多尺寸自适应 | 500×600 / 500×160（矮窗）/ 340×640（窄屏）均通过渲染回归 |

## 技术要点

- **零外部资源**：无 CDN / 图片 / 字体 / 音频文件。球与管子全部用 Canvas 路径绘制，音效用 WebAudio 振荡器合成。
- **单文件可运行**：`file://` 直接打开即可玩；`localStorage` 全部包在 `try/catch` 中（隐私模式下不崩）。
- **确定性每日题面**：`hashSeed`（FNV-1a）+ `mulberry32` 注入 `randomFill(colors, empties, rnd)`，同日期必得同一题面；普通关卡不传 `rnd` 时仍走 `Math.random`，行为完全不变。
- **分级生成预算 + 自适应遮罩**：关卡用「随机填充 + 求解器校验」保证可解。校验按 `GEN_STAGES=[40,120,400]` 分阶段花预算——先用目标空管数（更难）试 40 次，不行再逐级加空管兜底，总尝试硬上限 400 次，实测 1~40 关平均 **27ms**（此前 100ms，最慢 219ms）。遮罩不再是必弹：只有上次生成 >60ms 时才先出遮罩让出主线程，否则同步生成，避免普通关卡「闪一下」。`genToken` 防止快速切关时旧生成覆盖新关。
  > 预算刻意用**尝试次数**而非墙钟时间：每日谜题靠它保证「全服同一题面」，若按耗时切换阶段，不同快慢的设备会得到不同题面。
  > 生成诊断信息在 `genStats{tries,ms,empties,colors}`，控制台可直接查看。
- **可回滚的手感层**：倒球动画只负责表现，逻辑态即时更新；动画期间锁输入，避免状态机串扰。
- **生成质量不变量**（三条硬约束，均有测试断言）：
  1. **不丢球**：`randomFill` 用「未满管索引表」等概率取管，球数恒为 `colors*CAP`、每色恰好 `CAP` 颗（旧实现"随机试 50 次、失败就丢球"会让某色只剩 `CAP-1` 颗，生出"少一颗也能通关"的畸形关卡）。
  2. **开局不是已完成态**：`isWin` 只要求「每管空或单色」，随机填充有概率直接给出已排好的盘面（2 色 2 空管时实测 **3.27%**，即第 1/2 关），这类题面上 `win()` 不会触发（只在移动后判定），玩家会卡在"已经摆好却不通关"的坏关里 → 生成时用 `if(isWin(cand)) continue;` 拦掉，兜底分支也改为「从已排好退一步」。
  3. **撤销保持管数守恒**：加管不入撤销栈，`doUndo()` 回填后按 `baseTubes + addedTubes` 把付费空管补回管尾，不会出现"管子被吞、加管次数白扣"。
- **参考步数基准（限步 / 星级同源）**：生成时求解器返回 `{first, steps}`，`steps` 作为该关**参考步数** `refSteps` 存进关卡结构；`moveLimit = ceil(refSteps × 1.35)`（第 7 关起）、`par = ceil(refSteps × 1.15)`（星级），两者**同源同出口**，改基准只需改一处系数。`refSteps` 是 DFS 首次命中的解、**不是最短解**（实测 ≈1.4× 真最优），故系数按"相对 refSteps 的余量"定，避免把关卡卡成不可过。
- **评级文案三处一致**：星级口径散落在 `calcStars()` / 胜利弹窗说明 / help 规则条目三处，**必须同步改**（漏一处就是"默默扣星"）。已加表驱动断言（8 条路径 × 「声明上限 == 实得星级 == 显示文案」）长期守卫。
- **经济系统**：金币**有进有出** —— 产出（签到 / 每日首通 / 分享 / 广告 / 通关）与消耗（道具商城：提示券 / 撤销券 / 护星徽章 / 皮肤）闭环。**合规**：商城只支持金币兑换，**不含任何付费买金币入口**（无版号状态的唯一安全形态）。
- **变现钩子**：激励视频（+5 步 / 金币）、内购去广告卡均为占位实现，接入微信小游戏后替换为 `wx.createRewardedVideoAd` / `wx.requestMidasPayment`。


## 设计红线（四约束）

1. 单指点击操作，3 秒内理解玩法
2. 难度渐进递升，不靠数值售卖
3. 广告与内购钩子保留，但不影响可玩性
4. 零外部资源依赖，单文件可运行

## 部署

站点由 GitHub Actions 自动发布（`.github/workflows/pages.yml`）：推送到 `main` 即触发，产物只包含 `index.html`（设计文档与迭代日志不会被公开成网页）。

**首次启用需要一次性手动设置**（GitHub 限制：workflow 的 `GITHUB_TOKEN` 无权自行创建 Pages 站点）：

> Settings → Pages → Build and deployment → **Source 选「GitHub Actions」** → 保存

之后每次推送 `main` 都会自动重新部署，地址不变。若选「Deploy from a branch」+ `main` / `(root)` 也可以，但那样会把仓库内所有文件都当作网页公开，此时应删除 `pages.yml`。
